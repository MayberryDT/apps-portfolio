Chartroom

A local second brain that helps an agent find the right source and connect related pages—while leaving a record of what changed.

I built Chartroom from the working GBrain and TypeSafe Jev integration, then extracted a clean MIT-licensed preview that someone else can install with their own model keys. It runs locally through MCP and the command line; it is not a hosted knowledge service or a finished autonomous editor.

Make connections inspectable

CaptureSave a document in GBrain.
JudgeJev scores retrieved passages and candidate links.
ConnectApply selected links against checked page revisions.
InspectRead receipts and history, or resume bounded graph work.

The design keeps a saved document even if enrichment fails. Link decisions carry source evidence; graph publication is conditional and records a recoverable receipt. The public package deliberately excludes my private brain, editorial controller, and Android viewer.

A small, reproducible check

17/20 → 20/20

Correct first search result with Jev off and on, using the same 30 synthetic notes and 20 questions. The first-pass median search time increased from 34 ms to 150 ms. This is a small demonstration, not a general accuracy claim.
