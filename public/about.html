Bio

Builder first.

I’m interested in what happens when software becomes part of someone’s day. The details matter: keeping track of the source, making the next action clear and letting a person step in when they need to.

That takes me from agents that use a computer to tools for keeping knowledge, planning work and making things. Some projects become products; others are experiments I want to see through. My main project is ibara, which gives AI agents computers of their own. My company, Cirlet, helps independent insurance agencies put AI and automation to work. This site is the canonical personal site for Tyler Mayberry.

The common thread is practical product engineering. I like turning vague, high-friction work into concrete systems people can understand, operate, and improve.

Selected work

A few things I’ve made.

Main project

ibara

Computers of their own for AI agents: they use the browser and desktop apps there while you keep working on yours. Any agent that speaks MCP can drive it. It runs on Omarchy, Ubuntu and Windows.

Game

Siege of Champions

A 3v3 MOBA that runs in a desktop browser. Play solo with bots or invite friends to a private room; nothing to install and no account. An early playtest with numbered patches.

Desktop app

ytfast

A native YouTube Music player for Omarchy, written in Rust. Audio only, themed by Omarchy, with no browser engine and no telemetry. Open source.

Product

ChartStead

Conference programming and speaker management software. Keep the call, review, speaker work, messages, and agenda together, then publish the public program when your team is ready. Live site, sample-data demo, and MIT-licensed source.

Product

Masthead

A local-first session data layer for AI coding agents: capture harness work into SQLite, publish knowledge artifacts through Workbench, and retrieve them via read-only MCP. Electron desktop app for macOS and Linux.
